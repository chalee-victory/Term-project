# 텀프로젝트 (4조) 내용 요약 및 작업 결과

## 프로젝트 개요
* **프로젝트명:** AI 기반 UI/UX 디자인 시안 제작
  * 텍스트 프롬프트 기반 생성형 AI 이미지를 실무 UI/UX 시안 및 Figma 프로토타입으로 구체화하는 프로젝트
* **프로젝트 목적:** 생성형 AI를 실무 파이프라인에 이식하여, 기획 의도를 정교한 UI/UX 시안으로 구체화하는 비주얼 커뮤니케이션 역량을 확보한다. 텍스트 프롬프트로 도출한 시각적 결과물을 Figma와 결합해 실제 작동하는 프로토타입으로 완성하는 전 과정을 경험한다.
* **프로젝트 목표:**
  * 프롬프트 구성 요소(스타일·레이아웃·색상 등)가 결과물에 미치는 영향을 설명할 수 있다.
  * AI 생성 이미지의 문제점(텍스트 깨짐, 부자연스러운 요소)을 식별하고 수정할 수 있다.
  * 이미지 일관성 유지 방법(시드 고정, 이미지 레퍼런스 등)을 설명할 수 있다.
  * 기획 → 이미지 생성 후가공 → 프로토타입으로 이어지는 AI 협업 워크플로우를 설명할 수 있다.
